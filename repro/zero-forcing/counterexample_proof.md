# 猜想 A 的一个树反例：396 个顶点

日期：2026-10-29。本文沿用原 PDF 的定义：

\[
W(J)=V\setminus N[J],\quad B(J)=N(J)\cap N(W(J)),
\]

配置为 \((J,S,\chi,T)\)，其中 \(J\) 独立、\(V\setminus J\) 为零强制集，\(S\subseteq B(J)\)，\(\chi\) 为 \(G[J\cup S]\) 的正常二着色，\(T\subseteq V\setminus N[J\cup S]\)。所有颜色选择与集合选择都按原定义计数。

**结论：猜想 A，即对所有有限简单图都有 \(\tau(G)\le 8^{|V(G)|/2}\)，不成立。下面给出一个树反例及不依赖递推程序的直接计数证明。**

## 1. 构造

对正整数 \(m,\ell\)，构造树 \(T_{m,\ell}\)：

1. 取一个顶点 \(r\)，接上 \(\ell\) 个不同顶点 \(h_1,\ldots,h_\ell\)。
2. 对每个 \(h_i\)，接上 \(m\) 条互不相交的三边臂
   \(h_i-a_{ij}-b_{ij}-c_{ij}\)。除此以外没有边。

于是

\[
|V(T_{m,\ell})|=1+\ell(1+3m).
\]

取 \(m=26,\ell=5\)，得到 \(396\) 个顶点、\(395\) 条边的树，最大度为 \(27\)，直径为 \(8\)。它当然也是连通二部图。

## 2. 一条臂的 22 种封闭配置与 4 种待完成配置

先看路径 \(a-b-c\)。下面四类是其全部合法核心及相应配置数：

| 核心 \(J\) | 配置数 | 说明 |
|---|---:|---|
| \(\varnothing\) | 8 | \(S=\varnothing\)，\(T\) 为任意子集 |
| \(\{a\}\) | 6 | \(S=\varnothing\) 时 4 种；\(S=\{b\}\) 时 2 种 |
| \(\{b\}\) | 2 | \(S=T=\varnothing\)，核心有两种颜色 |
| \(\{c\}\) | 6 | 与 \(\{a\}\) 对称 |
| 合计 | **22** | |

称它们为封闭配置。它们的核心能在这条臂内部被强制完成；外部顶点 \(h\) 不必执行强制。22 种之中，\(a\notin J\) 的有 \(8+2+6=16\) 种。

另外允许一类待完成配置：

\[
J=\{a,c\},\quad S=T=\varnothing.
\]

\(a,c\) 各有两种颜色，故有 **4** 种。此时可以由外部顶点 \(h\) 强制 \(a\)，再由 \(b\) 强制 \(c\)。这四种并不是路径本身的合法配置；它们只作为整个树中的局部选择，在下文给出全局强制顺序后才计入。

这里所有臂上的 \(S\) 都只可能含 \(b\)。因此，若 \(h\notin J\cup S\)，不同臂之间不会产生新的着色约束；臂内选中的 \(S\) 仍有原来的核心邻点与 \(W(J)\) 邻点。

## 3. 一个分支中心的两类选择

记

\[
F=22^m,\qquad O=4m22^{m-1},\qquad C=F+O.
\]

将 \(h\) 及其 \(m\) 条臂作为一个分支。以下始终禁止 \(h\in J\cup S\)。

- 所有臂均选封闭配置：共 \(F\) 种，称为自由类。
- 恰有一条臂选待完成配置，其余选封闭配置：共 \(O\) 种，称为占用类。

类的划分由具体核心和臂上的配置唯一决定，没有选择或计数匹配，也没有标记强制顺序。

### 根 \(r\) 属于核心时

此时 \(h\in N(J)\setminus S\)，不属于 \(T\)。两类都允许，共 \(C\) 种。自由类在臂内强制结束后，\(h\) 可强制 \(r\)；占用类则还留有待完成臂的核心顶点。

### 根 \(r\) 不属于核心时

我们只保留以下选择：\(h\) 被核心支配但不在 \(S\)，或 \(h\in T\)。

- 若 \(h\in N(J)\setminus S\)，至少一条臂的 \(a\) 必须属于核心。自由类中不满足此条件的恰有 \(16^m\) 种；占用类自动满足。因此共 \(C-16^m\) 种。
- 若 \(h\in T\)，其所有邻点都不能属于核心或 \(S\)。根 \(r\) 在本情形不属于核心或 \(S\)，每条臂恰可选上述 \(a\notin J\) 的 16 种封闭配置，故共 \(16^m\) 种。

两项相加，仍为 **\(C\)**。不同选择给出不同的 \((J,S,\chi,T)\)，没有重复。

## 4. 显式合法子族的总数

把这些分支接到根 \(r\)。我们计数两个互不相交的子族。

**第一族：\(r\in J\)。** 根的颜色有两种。\(\ell\) 个分支各选自由类或占用类，但要求至少有一个自由类。因此有

\[
2(C^\ell-O^\ell)
\]

种。零强制顺序明确如下：先完成所有封闭臂；选择一个自由类中心 \(h_i\) 强制 \(r\)；此后，每个占用类中心都只有其待完成臂的 \(a\) 一个白邻点，先强制该 \(a\)，再由对应 \(b\) 强制 \(c\)。这完成全部核心顶点的强制。

**第二族：\(r\notin J\cup S\)。** 每个分支按上一节的 \(C\) 种方式选择，因此所有 \(h_i\notin J\cup S\)，从而 \(r\in W(J)\)，且不邻接 \(S\)。根可以属于 \(T\)，也可以不属于 \(T\)，共

\[
2C^\ell
\]

种。先完成所有封闭臂，再由每个占用类中心处理其唯一待完成臂，就给出合法零强制顺序。

两族中的 \(J\) 均独立。臂上 \(S\) 的两个邻点见证保持有效，所以仍有 \(S\subseteq B(J)\)；没有新的支撑边连接不同臂或根，故着色条件保持成立。所有新增 \(T\) 顶点的邻点均避开 \(J\cup S\)，故 \(T\subseteq V\setminus N[J\cup S]\)。因此它们确实都是原 PDF 定义下的配置。

综上，得到纯组合下界

\[
\boxed{\quad
\tau(T_{m,\ell})\ge
4\bigl((22+4m)22^{m-1}\bigr)^\ell
-2\bigl(4m22^{m-1}\bigr)^\ell.
\quad}
\]

这是一个明确子族的计数，不是把强制序列数或匹配数误当作配置数。

## 5. 有限整数不等式完成反例

取 \(m=26,\ell=5\)，有

\[
C=126\cdot22^{25},\qquad O=104\cdot22^{25}.
\]

上述子族的数量为

\[
\begin{aligned}
L&=4(126\cdot22^{25})^5-2(104\cdot22^{25})^5\\
 &=2^{132}\,11^{125}\,(63^5-512\cdot13^5)\\
 &=2^{132}\cdot802334527\cdot11^{125}.
\end{aligned}
\]

另一方面，猜想上界为 \(8^{396/2}=2^{594}\)。所需比较恰好化为

\[
802334527\cdot11^{125}>2^{462}.
\]

这是一条严格的整数不等式；其左边减右边等于

```text
71041496620408718939657909701284346505350728572411523610306384876079639525250786345959451505329521800104359601985680688563118120949394373
```

因此

\[
\boxed{\tau(T_{26,5})\ge L>8^{198}.}
\]

更强地，\(200L>201\cdot8^{198}\)，即仅这个子族就已超过猜想上界的 0.5%。其实际比值为

\[
\frac{L}{8^{198}}=1.0059655996599006476897879490885386\ldots
\]

浮点或小数不参与反例的判定；上面的整数不等式已经完成证明。最短复核如下，只需要 Python 标准整数：

```python
C = 126 * 22**25
O = 104 * 22**25
L = 4*C**5 - 2*O**5
assert L == 2**132 * 802334527 * 11**125
assert 200*L > 201*8**198
```

2. 对明确构造的 396 点树，用原 13 状态递推分别在中央根、分支中心、末端叶子处选根，总数一致。

完整整数、边表及整数比较余量保存在 `counterexample_certificate.json`。该总数是额外计算结果；第 1–5 节的反例证明只依赖显式子族与整数幂比较。

**猜想 A 已被否定。** 取这个反例的任意多个不交并，并使用 \(\tau\) 的乘法性，即得到无限多个反例。因此若对所有图或所有森林提出统一指数上界 \(\tau(G)\le c^{|V(G)|}\)，其底数必须严格大于 \(\sqrt8\)。本轮另有适用于所有森林的 \(2.85^{|V(F)|}\) 精确证书；它与本反例相容。

此前已证明的低最大度森林、毛毛虫树及直径至多 4 的树等特例不受影响：本反例的最大度为 27、直径为 8，且不是毛毛虫树。

**猜想 B 若单独表述为“等号恰在 \(K_2,P_4\) 的不交并发生”，其独立真伪没有被本反例决定。** 超过上界并不自动产生新的等号图。本反例否定的是猜想 A 及以它为依据的一般极值上界。
